# Mærkedage – test-udgivelser

Seneste testversion af Android-appen **Mærkedage** (fødselsdage og mærkedage som widgets på hjemmeskærmen).

**Version:** 0.15.3 (build 18, 2026-11-06T11:50:12Z)

## ⬇️ Hent
**[Markdays-latest.apk](https://github.com/renegreth/MarkdaysReleases/raw/main/Markdays-latest.apk)**

Linket peger altid på den nyeste version.

## Installér
1. Åbn linket ovenfor på din Android-telefon og hent filen.
2. Tryk på den hentede fil. Første gang beder telefonen dig tillade installation fra
   browseren/filhåndteringen ("ukendte kilder") – tillad det.
3. Opdatering: installér den nye fil oven på den gamle. Dine mærkedage og widgets bliver liggende.

Kræver Android 8.0 eller nyere. Det er en testversion (debug), ikke fra Google Play.
